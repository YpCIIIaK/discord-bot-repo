# discord-bot-repo

Краткое описание проекта: Discord-бот на Node.js.

## Установка
```bash
git clone https://github.com/YpCIIIaK/discord-bot-repo.git
cd discord-bot-repo
npm install
```

## Запуск
```bash
cp .env.example .env   # заполнить DISCORD_TOKEN
npm start
```

## Структура
```
src/        — исходный код бота
.env        — секреты (не коммитить)
README.md   — этот файл
```

## Безопасность
- Токен бота хранить только в `.env`, добавить его в `.gitignore`.
- Не логировать содержимое токена и приватные сообщения.
- Ограничивать права бота (минимально необходимые интенты).

## Тестирование
Проверка проекта перед коммитом:

1. Установить зависимости: `npm install`.
2. Запустить линтер (если настроен): `npm run lint`.
3. Запустить тесты: `npm test`.
4. Запустить бота в тестовом окружении с тестовым токеном и убедиться,
   что он подключается к Discord и отвечает на базовые команды.
5. Проверить, что `.env` не попал в индекс Git: `git status` не должен
   показывать файл `.env`.

Если автоматические тесты ещё не настроены, добавьте их через Jest
(`npm i -D jest`) и храните тесты в каталоге `tests/`.
